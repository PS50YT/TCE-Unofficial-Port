## Features

* 🚗 Cars and other vehicles
* 🛞 Vehicle parts and systems
* 🎨 Vehicle painting with the spray can
* 📖 TCE shortcut/book system
* ⚙️ Vehicle configuration and functions
* 🔧 Ported for newer versions with fixes

# How to use


Use the command ```/function tce:```to get a shortcut book to the features of the mod. You can also get items and summons vehicles using the book.

If vehicle is not spawing and shows ```[TCE] Can't give [car_item] while disabled [ENABLE]``` in your chat then use the command ```/function tce:on```


## Porting

This version contains modifications required to make the original TCE content work with Minecraft 26.1.2 and Fabric.

Original project: The Car Engine (TCE)

Please report compatibility issues with the 26.1.2 port on this project rather than assuming they are bugs in the original TCE release.
